# World’s First Human Function World Model Built on UOHF, with the Whole Person as the Persistent Modeling Object, Enters Gray Release

**Release date: 2026-10-02**

MoveTips Human Function has officially entered its gray-release stage.

The central point of this release is the **whole person**.

MoveTips does not model a person as separate medical, rehabilitation, exercise, nutrition, psychological, or daily-life fragments. It uses the **same whole person as the persistent modeling object** and **human function as the organizing coordinate** across time.

Built on the **Unified Ontology of Human Function (UOHF)**, the Human Function World Model connects medical care, rehabilitation, exercise, nutrition, psychology, and everyday bodily changes while preserving the professional identity and boundaries of each domain.

Its purpose is not merely to record isolated events or measurements. The model continuously relates:

> **task and demand → required human functional capacities → actual functional engagement → evidence and response → cost, boundary, reserve and recovery → current human-function state → action → longitudinal change and feedback**

Through the Body Function Report, these changes can be represented around the same person over time.

The model therefore asks not only:

> **What happened?**

but also:

> **Why did these changes, together, result in the current problem in this particular person?**

This is the distinction behind the phrase **whole-person Human Function World Model**: the modeling object does not change when the person moves between medical care, rehabilitation, exercise, nutrition, psychological support, or everyday life. The person remains the same continuous individual, and the model keeps updating around that person.
